# Debut Loop! — 아이폰 설치 가이드 (디자이너용)

> 준비물: Xcode 설치된 맥북, 아이폰 + 케이블, Apple ID (무료 계정 OK)

## 1. 프로젝트 열기
1. 이 zip을 풀고 `ios/App/App.xcodeproj` 를 더블클릭 → Xcode가 열립니다
2. 처음 열면 패키지 로딩(진행바)이 잠깐 돕니다 — 끝날 때까지 대기

## 2. Apple ID 로그인 (최초 1회)
1. 메뉴 **Xcode → Settings → Accounts** 탭
2. 왼쪽 아래 **+** → **Apple ID** → 본인 Apple ID로 로그인

## 3. 서명 설정 (최초 1회)
1. 왼쪽 파일 목록 맨 위 파란 아이콘 **App** 클릭
2. 가운데 **TARGETS → App** 선택 → **Signing & Capabilities** 탭
3. **Automatically manage signing** 체크
4. **Team** 드롭다운에서 본인 이름 **(Personal Team)** 선택
5. ⚠️ "identifier is not available" 빨간 에러가 뜨면:
   **Bundle Identifier** 를 `com.debutloop.game.본인이니셜` 로 살짝 바꿔주세요 (예: `com.debutloop.game.kim`)

## 4. 아이폰 준비 (최초 1회)
1. 아이폰을 맥북에 케이블로 연결 → "이 컴퓨터를 신뢰" 허용
2. 아이폰에서 **설정 → 개인정보 보호 및 보안 → 개발자 모드** 켜기 → 재부팅

## 5. 설치 (Run)
1. Xcode 상단 중앙의 기기 선택에서 **본인 아이폰** 선택 (시뮬레이터 아님!)
2. 왼쪽 위 **▶ (Run)** 버튼 클릭 → 빌드 후 아이폰에 자동 설치·실행
3. 처음엔 아이폰에 "신뢰되지 않은 개발자" 가 뜹니다:
   **설정 → 일반 → VPN 및 기기 관리 → 본인 Apple ID → 신뢰** 후 앱 다시 실행

## 6. 이후 유지
- **7일이 지나면 앱이 안 열립니다** (무료 계정 서명 만료) → 아이폰 연결하고 **▶ Run 한 번**이면 다시 7일 연장 (게임 데이터 유지)
- 새 버전 zip을 받으면: 기존 폴더를 지우고 새 zip을 풀어 1번부터 다시 (2~4번 설정은 유지되어 있어 ▶ Run만 하면 됩니다)

문제가 생기면 에러 메시지 스크린샷과 함께 문의해주세요 🙋
