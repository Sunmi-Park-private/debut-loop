# Debut Loop! — 맥북 시뮬레이터 테스트 가이드 (디자이너용)

> 아이폰 없이 맥북만으로 아이폰 앱을 테스트하는 방법입니다.
> 실기기 설치 가이드는 `아이폰-설치-가이드.md` 참고 — **시뮬레이터는 Apple ID 로그인·서명·키체인이 전부 필요 없어서 더 간단합니다.**

## 1. Xcode 설치 (최초 1회, 오래 걸림)

1. 맥북에서 **App Store** 열기 → "Xcode" 검색 → **받기** (무료, 수십 GB — 와이파이에서 여유 있을 때)
2. 설치가 끝나면 **Xcode를 한 번 실행** → 라이선스 동의 창이 뜨면 **Agree** → 필수 컴포넌트 설치 대기

## 2. iOS 시뮬레이터 런타임 설치 (최초 1회, ~8.5GB)

1. Xcode 처음 실행 시 **"Select the platforms to develop for"** 화면이 나오면 **iOS 체크** 후 다운로드
2. 그 화면을 놓쳤다면: 메뉴 **Xcode → Settings → Components** 탭 → **iOS xx.x** 옆 **GET/다운로드** 버튼
3. 다운로드가 끝나야 아이폰 시뮬레이터가 생깁니다

## 3. 프로젝트 열기

1. 전달받은 zip을 풀고 `ios/App/App.xcodeproj` 더블클릭 → Xcode가 열립니다
2. 처음엔 패키지 로딩(진행바)이 잠깐 돕니다 — 끝날 때까지 대기
3. ⚠️ 실기기와 달리 **Apple ID 로그인, Team 선택, 서명 설정이 전혀 필요 없습니다** — 3~4단계를 건너뛰세요

## 4. 시뮬레이터에서 실행

1. Xcode 상단 중앙 기기 선택에서 **iPhone 17** (또는 아무 iPhone 시뮬레이터) 선택
  - 실기기 이름이 아니라 **"iPhone 17 (Simulator)"** 처럼 시뮬레이터를 골라야 합니다
2. 왼쪽 위 **▶ (Run)** 클릭 → 빌드 후 가상 아이폰 창이 뜨고 앱이 자동 실행됩니다
3. 마우스 클릭 = 터치, 키보드 입력도 그대로 전달됩니다

## 5. 새 버전 받았을 때

기존 폴더를 지우고 새 zip을 풀어 `App.xcodeproj` 다시 열고 **▶ Run** — 끝.  
(시뮬레이터·Xcode 설정은 그대로 유지됩니다)

## 문제 해결

- **"Unable to boot simulator"**: 시뮬레이터 앱 완전 종료(⌘Q) 후 다시 ▶ Run
- **빌드 에러**: 에러 메시지 스크린샷과 함께 문의
- **시뮬레이터 목록에 iPhone이 없음**: 2단계(iOS 런타임 다운로드)가 안 된 것

문제가 생기면 스크린샷과 함께 문의해주세요 🙋

## 6. 자주 쓰는 조작


| 하고 싶은 것     | 방법                    |
| ----------- | --------------------- |
| 화면 회전       | ⌘← / ⌘→               |
| 홈으로         | ⌘⇧H                   |
| 스크린샷 저장     | ⌘S (데스크탑에 저장됨)        |
| 앱 다시 시작     | Xcode에서 ▶ 다시 클릭       |
| 시뮬레이터 크기 조절 | 창 모서리 드래그 또는 ⌘1/⌘2/⌘3 |
