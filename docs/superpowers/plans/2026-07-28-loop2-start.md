# 2회차 시작 개선 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 2회차 시작 시 유저가 ⚡빠른 모드(seen 비트 탭 1회 넘기기 + 1회차 선택 재적용) / 📖정속 모드(1회차와 동일)를 선택하게 하고, 2회차 오프닝 서사를 정리한다.

**Architecture:** 엔진(`engine/`)은 선택 방향을 `State.choices`에 기록하고 회귀 시 계승만 한다(재적용 전용 로직 없음 — UI가 기록된 방향으로 기존 `choose()`를 호출). UI(`ui/`)는 회귀 엔딩 화면에서 모드를 고르게 하고, 빠른 모드에서 seen 비트를 탭 카드로 렌더한다. 데이터는 w0 오프닝 비트의 loop 지정만 바꾼다.

**Tech Stack:** TypeScript + PixiJS v8 + Vite + Vitest. 스펙: `docs/superpowers/specs/2026-07-28-loop2-start-design.md`

## Global Constraints

- **git 레포 미생성** — 커밋 단계 없음. Director가 레포 생성 후 일괄 커밋 (각 Task 끝에서 변경 파일만 확인).
- **빌드(APK·단일 HTML)는 Director 요청 시에만** — 검증은 `npx tsc --noEmit` + `npx vitest run` + dev 서버까지.
- 주석·문구는 한국어, 식별자는 영어. 기존 파일 스타일(간결한 한 줄 주석) 준수.
- 작업 디렉토리: `debut-loop` (UACOS 레포 아님 주의).
- act 관문 반복·주간 연습은 **변경 금지** (스펙 D절 — 현행 유지 확정).

    let done = false;
    const finish = (): void => {
      if (done || card.destroyed || !card.parent) return;
      done = true;
      offSpace();
      window.removeEventListener("keydown", onKey);
      onChoose(replay);
    };
    card.on("pointertap", finish);
    const offSpace = pairSpace(finish, () => !done && !card.destroyed && !!card.parent);
    const onKey = (e: KeyboardEvent): void => {
      if (card.destroyed || !card.parent) { window.removeEventListener("keydown", onKey); return; }
      if (e.repeat) return;
      const tag = document.activeElement?.tagName;
      if (tag === "INPUT" || tag === "TEXTAREA" || tag === "SELECT") return;
      if (e.code === "ArrowRight") { e.preventDefault(); finish(); }
    };
    window.addEventListener("keydown", onKey);
    card.on("destroyed", () => window.removeEventListener("keydown", onKey));
  }
