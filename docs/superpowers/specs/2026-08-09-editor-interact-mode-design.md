# 레이아웃 에디터 — 조작 모드와 그리드 설계

> 작성일 2026-08-09 · 대상 브랜치 `fix/audition-feature`

## 문제

에디터를 켜면 투명 실드가 화면을 덮어 게임 입력을 전부 삼킨다. 컴포넌트를 어디서든 드래그로
잡으려면 필요한 구조지만, 그 탓에 `확정`·`계속` 같은 버튼이 눌리지 않아 **화면을 진행할 수 없다.**
원하는 장면까지 가려면 에디터를 껐다가, 도착해서 다시 켜야 한다. 끄면 선택 상태가 날아가고
화면이 다시 그려진다.

편집 중인지 아닌지도 화면만 봐서는 알 수 없다. 실드가 알파 0.001로 보이지 않기 때문이다.

## 목표

- 에디터를 켠 채로 게임을 진행할 수 있다 — 패널·선택·미저장 편집을 유지한 채
- 지금이 편집 중인지 한눈에 보인다
- 드래그로 정렬하기 쉽다

## 두 모드

"에디터 켜짐"이 *패널이 떠 있다* 와 *게임 입력을 막는다* 를 동시에 뜻하던 것을 분리한다.

| | 패널 | 실드·그리드 | 게임 | 드래그 이동 | x/y 입력칸 |
|---|---|---|---|---|---|
| **✋ 편집** | 보임 | 있음 | 멈춤 | 가능 | 가능 |
| **▶ 조작** | 보임 | 없음 | 정상 | 불가 | 가능 |

전환은 **`` ` ``(백틱)** 또는 패널 상단 토글 버튼. 입력칸에 포커스가 있으면 단축키를 무시한다
(문구를 타이핑하다 모드가 뒤집히는 사고 방지).

에디터를 완전히 끄면 조작 모드도 함께 풀린다.

## 그리드

편집 모드에서만 실드 위에 크로마키 초록 그리드를 그린다. 흰색 베일 대신 선을 쓰는 이유는,
디자이너가 **색상과 슬롯 농도를 조정 중**이라 화면 전체에 흰색을 덮으면 색 판단이 흐려지기
때문이다. 선은 대부분 픽셀을 원본 그대로 둔다.

| 요소 | 간격 | 알파 |
|---|---|---|
| 잔선 | 10px | 0.12 |
| 굵은선 | 50px | 0.30 |
| 중앙선 (x=215) | — | 0.55 |
| 가장자리 테두리 | — | 0.45 |

캔버스 논리 폭이 430이라 50px 굵은선이 균등하게 떨어진다. 중앙선을 가장 밝게 두는 것은
지금까지 반복해서 문제가 된 것이 가운데 정렬이기 때문이다.

## 스냅

드래그하면 좌표가 **10px 격자에 붙는다**. 미세 조정 경로를 함께 둔다.

- **`Alt`를 누른 채 드래그** → 스냅 해제, 1px 단위
- **패널의 `x`/`y` 입력칸은 항상 정확한 값** — 격자로 대충 맞춘 뒤 숫자로 다듬는 흐름

기존에 저장된 격자에 맞지 않는 좌표는 건드리지 않는다. 그 컴포넌트를 다시 드래그할 때만 붙는다.

## 코드

대부분 `src/ui/editor.ts`에서 끝난다.

```ts
let interact = false;
export const inputBlocked = (): boolean => on && !interact;
```

게임 쪽은 "에디터가 켜졌는지"가 아니라 "입력이 막혔는지"를 보게 바꾼다.

| 위치 | 지금 | 바뀜 | 이유 |
|---|---|---|---|
| `swipeCard.ts` 탭-넘기기 | `!editorEnabled()` | `!inputBlocked()` | 조작 모드에서 2회차가 넘어가야 |
| `swipeCard.ts` 스와이프 | `!editorEnabled()` | `!inputBlocked()` | 조작 모드에서 선택이 되어야 |
| `minigames.ts` 일시정지 | `editorEnabled()` | `inputBlocked()` | 조작 모드에서 미니게임이 돌아야 |

`editorEnabled()`는 치트 메뉴 라벨용으로 남긴다.

`editable()`이 매 렌더마다 `mountShield()`를 부르므로, 조작 모드에서는 다시 씌우지 않도록 막는다.

## 경계

- 조작 모드에서 화면이 바뀌어도 패널은 새 화면의 컴포넌트로 갱신된다
- 선택 하이라이트는 조작 모드에서도 따라다닌다 — 어떤 요소를 보는 중인지 놓치지 않게
- 자동 저장은 모드와 무관하게 동작한다
- 그리드는 입력을 가로채지 않는다 (`eventMode = "none"`)

## 검증

**유닛** — `inputBlocked()`가 세 상태(꺼짐 / 편집 / 조작)에서 올바른 값을 낸다.

**수동**
- 편집 모드에서 `확정` 버튼이 안 눌리고, `` ` `` 로 조작 모드에 가면 눌린다
- 2회차 재생 카드가 조작 모드에서 탭으로 넘어간다
- 화면을 옮긴 뒤 편집 모드로 돌아와도 미저장 편집과 선택이 남아 있다
- 드래그가 10px에 붙고, `Alt` 드래그는 붙지 않고, 입력칸은 정확한 값을 받는다
