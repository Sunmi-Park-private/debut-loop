## 1. 배경 — 해결하는 문제

| # | 지적 | 이 컨셉의 해법 |
|---|---|---|
| ③ | 인과 어색: 플레이어의 리듬 성적이 '지원자'의 기량을 결정 | 내 플레이 = **심사 정확도**. 잘 포착하면 후보의 최대치가 드러나고(80), 놓치면 과소평가(50) |
| ⑪ | 오디션 무대가 관문 리듬과 동일 화면 (정체성 없음) | 심사석 프레임 · 후보 실루엣 · 킬포인트 노트 · 전용 문구로 차별화 |
| ④ | 재오디션이 기량을 깎을 수 있는데 안내 없음 | "재심사 — 이번엔 어떻게 보일지 몰라요" 한 줄로 서사적 정당화 |
| ⑨ | 하드 보너스 조건(+3, good 이상)이 어디에도 없음 | 모드 버튼에 명시: "본선 무대 · 집중 심사 +3" |

기각한 대안: A 합동 무대(하루가 합을 맞춤 — 차선), C 후보 전용 곡(비트맵 다수 제작 필요, 일정 부담), D 신규 미니게임(비용 최고).

## 2. 서사 프레임

후보가 무대에서 공연하고, 하루는 심사석에 앉는다. 떨어지는 노트 = **후보의 킬포인트**(고음·댄스 브레이크·표정). 제때 탭 = 그 순간을 심사표에 기록. 성적은 "후보를 얼마나 정확히 봤는가"다.

- PERFECT 포착 → 후보의 진짜 실력이 보인다 (기량 80 기준)
- CLEAR 수준 → 겨우 훑어봤다, 과소평가 (기량 50 기준)
- 실패 → 심사 불능, 이번 개최 무산
- 재오디션 → 재심사. 그날의 집중도에 따라 기량 평가가 오르내릴 수 있음 (하락 리스크의 서사화)
