# 튜토리얼 설계·구현 계획 (승인본)

> 2026-07-24 브레인스토밍 확정. 목표: 유저가 게임 조작을 자연스럽게 파악.
> **범위 제외**: 메타(회귀 구조·광고 1회 더) 설명 — Director 지시.

## 확정 사항

| 결정 | 내용 |
|---|---|
| 배치 전략 | **하이브리드** — 프롤로그에 개념 직조 + 인게임 첫 등장 시점 1회 가이드 |
| 안내 형태 | **캐릭터 가이드** — 캐릭터 초상 + 말풍선 오버레이 (탭 해제) |
| 재노출 | **기기당 1회** (localStorage `debutloop.tut.<id>`) + 치트 "🎓 튜토리얼 리셋" |

## 1. 프롤로그 직조 (확정 문안)

- 슬라이드 ①(사고)·②(회귀): 유지 — 몰입 우선, 설명 없음
- **슬라이드 ③ (스와이프 개념)**:
  > 이번 3년은 달라.
  > 운명이 갈림길을 내밀 때마다,
  > 어느 쪽으로 기울지는 내 손끝이 정해.
- **슬라이드 ④ (게이지 5종, 긍정톤)**:
  > 실력, 멘탈, 평판, 유대, 자본.
  > 이 다섯 개가 우리의 무기야.
  > 차곡차곡 키워서 — 이번엔 꼭 데뷔하자!

## 2. 캐릭터 가이드 트리거 (6종, 각 1회)

| id | 트리거 | 스피커 | 대사 |

| training | 첫 연습 비트 | 유월 | "연습하면 카드를 받아! 잘할수록 좋은 카드야. 모아뒀다가 큰 무대에서 쓰는 거지." |
| deck | 첫 카드 획득 직후 | 유월 | "받은 카드는 아래에서 위로 쓸어올리면 언제든 볼 수 있어." |

- 대사는 스토리 영역 — 변경 시 이 표만 수정.

## 3. 구현

- **신규** `src/ui/tutorial.ts`: `guide(id, speaker, text)` — DOM 오버레이(광고 모달 계층), 초상은 `assets.char()` 재사용(폴백 이모지), 탭 해제, localStorage 1회 가드, `resetTutorial()` export
- **수정**:
  - `boot.ts` 프롤로그 슬라이드 ③④ 문안 교체
  - `app.ts` 첫 카드/첫 연습/덱 훅 (각 1줄)
  - `minigames.ts` renderGate 진입 시 엔진별 훅 (1줄)
  - 치트 메뉴 "🎓 튜토리얼 리셋" 등록
- **검증**: playwright — 첫 노출 → 탭 해제 → 재노출 없음 → 리셋 후 재노출 · 기존 74 유닛테스트 무영향

## 4. 성공 기준

1. 신규 유저가 설명 화면 없이 스와이프·연습·관문 3종을 첫 조우에서 이해
2. 2회차(회귀 후) 가이드 재노출 0회 — 템포 유지
3. 가이드 미노출 상태로도 게임 진행 막힘 없음 (가이드는 보조, 차단 아님)
