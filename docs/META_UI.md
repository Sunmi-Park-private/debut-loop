# 메타 UI 기능 설계 v1.1 — 설정·상점·데일리·포토앨범

> 대상: `debut-loop`. 유저가 보는 **런 바깥 메뉴들** — "상용 게임 완성도" 인상 축.
> **확정 스코프(Director 2026-07-24): 실동작 없는 FE 셸** — "향후 확장을 고려하고 있다"는 신호가 목적.
> 실제 저장·정산·오디오·다국어 로직은 본선 확장(아래 원설계 유지). 데모 = 열리고·눌리고·그럴싸한 화면.
> 구현: DOM 오버레이(파스텔) — Director 레퍼런스 UI 확보 시 스타일 교체 용이.

## 0. 공통 인프라 (모든 메뉴의 토대 — 최우선)

### 0-1. 메타 저장소 (`engine/save.ts` 스텁 활성화)
런(회차)과 무관하게 **브라우저 localStorage에 영속**되는 계정 데이터:
```ts
interface MetaSave {
  settings: { lang: "ko" | "en"; bgmVol: number; sfxVol: number; sns: SnsState };
  wallet: { star: number };            // ⭐ — 런 종료 시 획득분 적립(런 내 points → 정산)
  daily: { lastClaim: string; streak: number };   // "YYYY-MM-DD"
  album: string[];                     // 해금된 앨범 항목 id
  bestRecord: { loops: number; trueEnding: boolean };
}
```
- 순수 함수(`loadMeta`/`saveMeta`/기본값) + localStorage 어댑터 분리 → 유닛테스트 가능.
- **런 정산**: 엔딩/회귀 도달 시 `state.points` → `wallet.star` 적립(상점 재화 순환의 근원).

### 0-2. 진입점: 타이틀 화면 + 인게임 메뉴 버튼
- **타이틀 화면**(신규): 로고 + [게임 시작] [이어하기?] + 하단 아이콘 바(⚙️설정 · 🛍상점 · 🎁데일리 · 📔앨범)
- **인게임**: 헤더에 ☰ 버튼 → 같은 메뉴 오버레이(일시정지 성격). 개발 ⚙️치트와 분리.
- 모든 메뉴 = 파스텔 모달 오버레이(관문·연습과 같은 골드/파스텔 프레임 계열).

### 0-3. 오디오 매니저 (볼륨의 전제)
- 현재 오디오 없음 → `ui/audio.ts`: BGM 1트랙 + SFX 몇 종(탭·스와이프·카드획득·관문클리어) 슬롯.
- 에셋은 음원 준비 대기 — **슬롯+볼륨 배선만 먼저**(파일 없으면 무음, 에셋 드롭 규약과 동일 패턴).

## 1. ⚙️ 설정 메뉴

| 항목 | 데모 스코프 | 본선 |
|------|------------|------|
| **SNS 로그인 연동** | **목 UI**: Google/Apple/게스트 버튼 → 탭 시 "연동됨 ✓" 상태 저장(로컬). 실제 OAuth 없음 | 실 OAuth + 서버 세이브 |
| **언어 변경** | ko/en 토글 — **UI 라벨만** 문자열 테이블(`data/strings.json`)로 교체. 스토리 본문은 ko 유지(안내 문구) | 비트 textKey 다국어(`text: {ko, en}`) 확장 |
| **볼륨 조절** | BGM/SFX 슬라이더 2개 (0~100, 실동작) + 음소거 토글 | 동일 |
| 기타 | 크레딧(팀명) · 버전 표기 | 계정 삭제 등 |

- 언어 설계 포인트: 지금부터 **UI 라벨을 strings.json 경유**로 바꿔두면(하드코딩 제거) en 추가가 데이터 작업이 됨. 스토리(95비트) 번역은 데모 범위 밖.

## 2. 🛍 상점 메뉴

- **재화**: ⭐(런에서 벌어 메타 지갑에 적립). 현금 IAP는 **본선 목업**(가격표만, 결제 없음 명시).
- **판매 품목(데모)**:
  | 상품 | 가격(⭐) | 효과 |
  |------|:--:|------|
  | 카드팩 (랜덤 3장) | 15 | 다음 런 시작 덱에 추가 |
  | 티켓: 패자부활권 | 20 | 3단 사다리 안전망(스펙 §5) |
  | 스타터 부스트 | 10 | 다음 런 시작 게이지 +5 전체 |
- **설계 의미**: ⭐→상점→다음 런 강화 = **회귀 메타 루프**(로그라이크 상점 정석)와 스펙 §3(포인트로 티켓 구매)을 메타 층에서 회수.
- 데모 구현: 구매→메타 저장→새 런 생성 시 반영. 3품목이면 충분.

## 3. 🎁 데일리 보상 메뉴

- **7일 스탬프판**: 접속일마다 1칸(D1 ⭐5 → D7 에픽 카드 1장). 날짜는 로컬 기준 `YYYY-MM-DD` 비교, 연속 끊기면 streak 리셋(관대하게: 리셋 없이 다음 칸 진행도 옵션 — 튜닝).
- 수령 시 연출: 카드 획득 reveal 재사용.
- 데모 가치: 심사 기간에 재접속하면 실제로 동작하는 게 보임. 구현 가벼움(날짜 비교 + 지갑 적립).

## 4. 📔 포토앨범 (스펙 Q7 — 최종 수집 목표)

- **수집 항목(데모 ~10칸)**: 스토리 명장면 스틸 — 프롤로그 사고 / 5인 완성(W4) / 지하 첫 무대(W9) / 첫 앨범(W16) / 보라 각성(W17) / 진범 규명(W22) / 트루 엔딩 / 다크(회귀) / 관문 퍼펙트 등.
- **해금 트리거**: 비트 도달·플래그 달성 시 자동 해금(엔진에 `albumUnlocks` 매핑 데이터 — beats처럼 JSON).
- **UI**: 잠금(실루엣+?)/해금 그리드 → 탭하면 확대 + 한 줄 캡션. 이미지 = 에셋 슬롯(`public/assets/album/<id>.png`, 없으면 이모지 카드 플레이스홀더).
- 회귀·재플레이 동기의 시각화 — "트루 이후에도 회귀 계속(앨범 100%)" 스펙과 직결.

## 5. 우선순위 & 구현 순서 (제안)

| 순위 | 작업 | 근거 |
|:--:|------|------|
| 1 | **메타 저장소 + 런 정산(⭐)** (TDD) | 전 메뉴의 토대 |
| 2 | **타이틀 화면 + 메뉴 진입점** | 게임 첫인상 + 메뉴 거점. 제출 빌드 완성도 |
| 3 | **설정** (볼륨 실동작 + 언어 토글 + SNS 목) | 요구 3종 커버, 오디오 슬롯 포함 |
| 4 | **데일리 보상** | 가장 싸고 효과 큼 |
| 5 | **포토앨범** | 스펙 연결 + 에셋 슬롯(디자이너 산출물 활용처) |
| 6 | **상점** | 메타 루프 완성 — 밸런스 튜닝 필요해서 마지막 |

## 6. 열린 결정 (Director)
1. 각 메뉴 **비주얼 레퍼런스** (Director 수집 중) → 와이어프레임 리뷰 후 구현
2. 상점 품목·가격 초안 승인 여부 (위 3종/⭐가격)
3. 데일리 streak 정책(끊기면 리셋 vs 이어서)
4. 앨범 데모 칸 수(~10 제안)와 장면 선정
5. SNS 목 버튼 종류(Google/Apple/게스트 3종 제안)
6. 타이틀 화면 신설 OK? (현재는 바로 게임 시작)
