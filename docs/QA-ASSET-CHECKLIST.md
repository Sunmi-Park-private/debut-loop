# 자산(이미지·영상) 적용 QA 체크리스트

> **목적** — 업로드한 UI 아트·배경·영상이 본게임에 **누락 없이, 눌리지 않고, 올바른 위치에** 적용되었는지 시나리오 순서대로 검수한다.
> **범위** — UI 스킨 슬롯 141개 + 배경 슬롯 17개. 텍스트 문구(로컬라이징 대상)는 검수 대상에서 제외한다.
> **작성 기준일** — 2026-08-05
> **사용법** — 각 섹션 표를 구글시트에 붙여넣고 `판정` 열에 `Pass` / `Fail` / `N-A`를 입력한다.

---

## 0. 공통 판정 기준 · 사전 준비

### 0-1. 판정 기준 (각 행의 `기대 결과`가 참조하는 코드)

| 코드 | 기준 | 무엇을 보는가 |
|---|---|---|
| ① | **폴백 아님** | 업로드한 아트가 보인다. 벡터 도형(둥근 사각형·원)이나 이모지가 아니다. |
| ② | **비율 정상** | 가로/세로로 눌리거나 늘어나지 않았다. 원본 비율 그대로다. |
| ③ | **잘림 없음** | 상하좌우가 패널·화면 밖으로 잘리지 않는다. |
| ④ | **배율·위치 반영** | UI 에디터에서 조정한 배율·좌표가 실제 게임 화면에 그대로 적용된다. |
| ⑤ | **영상 재생** | mp4/webm이 자동 재생되고 끊김 없이 루프한다. 첫 프레임에서 멈추지 않는다. |

> **②가 자주 깨지는 이유** — 로더가 투명 여백을 자동 크롭(trim)하기 때문에 정사각 PNG여도 실제 아트는 비정사각이다. `stretch` 모드 슬롯에 비정사각 아트를 넣으면 눌린다.

### 0-2. 사전 준비

| 항목 | 방법 |
|---|---|
| 게임 실행 | `npx vite --port 5174 --strictPort` → `http://localhost:5174/` |
| UI 스킨 에디터 | `http://localhost:5174/ui.html` (슬롯 업로드·배율·농도) |
| 배경 에디터 | `http://localhost:5174/bg.html` |
| 레이아웃 에디터 | 게임 화면 우하단 **⚙️ 치트 메뉴** → 레이아웃 에디터 토글 |
| 치트 메뉴 | 우하단 상시 **⚙️** 버튼. 게임(회차) 진입 후에만 활성화되는 항목이 있다. |
| 화면 크기 | 430×800 기준(모바일 세로). 브라우저 창을 이 비율로 맞추고 검수한다. |

### 0-3. 검수 순서 (이 문서의 섹션 순서)

프롤로그 → 로딩 → 타이틀 → 메인 로비(+카드덱·데일리·앨범·상점·설정) → 게임 스토리(1회차 → 2회차 정속 → 2회차 빠른) → 연습하기 6종 → 관문 5막 → 오디션 영입 → 부록
